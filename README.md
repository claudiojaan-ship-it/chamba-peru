# Chamba Perú

Bolsa de trabajo del Perú: convocatorias del Estado, prácticas y empleos privados de las 25 regiones, con becas, bonos de vivienda y cursos gratis.

- Página: https://claudiojaan-ship-it.github.io/chamba-peru/
- Se actualiza sola dos veces al día (6:00 a. m. y 6:00 p. m., hora de Perú) con GitHub Actions: `.github/workflows/actualizar.yml`.
- Proceso: `tools/update.sh` descarga las convocatorias, prueba cada enlace, baja los logos y genera `site/`.
- Para actualizar a mano: pestaña **Actions** → **Actualizar convocatorias** → **Run workflow**.
